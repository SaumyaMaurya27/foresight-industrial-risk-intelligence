# Environment & Project Configuration

## Purpose
This directory manages configuration maps, tool specifications, and environmental blueprints, helping developers set up standardized workspaces.

## Directory Structure & Files
*   `.env.example` - Template showing keys required by frontend/backend services (database, port, Gemini API credentials).

## Why It Exists
Consolidates configuration variables in a single area, enforcing clean separation of logic from system variables, and protecting developers from accidentally committing credentials.
